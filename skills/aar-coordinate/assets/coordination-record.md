# 一轮协作记录

供已有单协调执行者保存到已登记的外部协作目录。已有同用途登记时复用它，不另建第二份真源。此文件是非权威观察记录，不是分布式锁、控制器事件或授权令牌；不含凭证。

## 本轮范围

- 本轮模式：只读汇总 / 执行一轮 / 恢复一轮 / 集成前检查。
- 协调执行者、更新时间、本轮固定工作项和候选集合：待填写。
- 已核对的 AGENT_RUNTIME_ROOT、各仓工作目录映射：待填写。
- 原始用户授权来源及范围：待填写；分别列出可通知目标、可发布仓库、可推送分支与可创建 PR 的目标。不记录虚构的授权，也不以此文件扩大授权。
- 本轮结束条件：已核对所有范围内工作项，或有明确阻塞并交给下一责任方；新增事件不自动无限扩展本轮。

## 单条待发送通知

以下内容在补齐并核对授权后发送；无消息工具时保留为“待发送”，不要自行改用未授权渠道。

- 工作项、原始事件、提供方提交及交接位置：待填写。
- 目标消费者、所属仓库、Worktree、项目和变体：待填写。
- 变化摘要、迁移文档、直接或传递影响路径：待填写。
- 阶段：草稿预告 / 候选就绪；就绪时附精确坐标、下载入口、SHA-256 与完整配套候选集合。
- 请求：在你拥有的 Worktree 中核验，按当前工作项采用候选并运行正式验证；当前构建期间不要改版本，稳定主线不跟随草稿。
- 返回：采用的候选、迁移提交、实际测试与收据、PR/CI 状态、阻塞和下一责任方。
- 权限边界：服从已有用户授权；本通知不授予额外发布、推送、合并或回发消息权限。

## 集成与恢复检查点

- 各仓已迁移/合并提交及实际采用制品：待填写，不把所有仓库当成一次 Git 合并。
- 固定集成清单、集成提交和报告：待填写。
- combination_verified、ready_for_integration、release_approved：逐项引用控制器原值，未知则写未知。
- 发送超时、部分发布、活动租约或旧 CI 等未决项：待填写；恢复时先查事实，不重复制造副作用。
- 需要用户处理的映射、权限或基础设施缺口：待填写。下一轮启动方式：人工调用，或已经获准且实际配置的调度工具；没有配置不得承诺自动唤醒。
